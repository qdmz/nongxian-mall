# 田冲助农商城 · 管理后台（Admin）

贵州亿田农业·田冲红色美丽乡村强村富民工坊 —— 党建引领乡村振兴助农电商平台管理后台。

## 技术栈

- Vue 3（Composition API + `<script setup>`）
- Vite 5
- Element Plus（党建红主题）
- Vue Router 4
- Pinia（token / 管理员信息）
- Axios（统一封装：Bearer token、错误提示、401 跳登录）
- ECharts（销售趋势、分类占比）
- dayjs（时间戳格式化）

## 启动方式

```bash
cd admin
npm install
npm run dev
```

访问 http://localhost:5173，默认账号 `admin / admin123456`

> 后端 API 默认运行在 `http://localhost:8000`，已通过 Vite proxy 代理 `/admin` 与 `/uploads` 前缀，无需额外跨域配置。

## 功能模块

| 模块 | 说明 |
|------|------|
| 仪表盘 | 今日/昨日/本月/累计统计、销售趋势（订单柱状+金额折线双 Y 轴）、分类销售占比饼图、最新订单、库存预警 |
| 用户管理 | 搜索/状态筛选、详情抽屉（基本信息+近期订单+钱包流水）、启用/禁用、调整余额、发站内信 |
| 分类管理 | 树形表格、新增/编辑/删除、红色助农专区标记、图片上传 |
| 商品管理 | 列表搜索/筛选、上下架、快速改库存、删除；新建/编辑完整表单（标签开关、助农信息、封面+轮播图上传、SKU 动态表格） |
| 订单管理 | 状态 tab + 订单号/日期/类型筛选、汇总条、发货弹窗（快递/自配送双模式）、取消订单 |
| 订单详情 | 订单信息、商品明细、收货信息、订单日志时间线、配送轨迹、退款处理 |
| 退款管理 | 状态筛选、同意/拒绝（拒绝必填原因） |
| 配送管理 | 配送列表、添加轨迹弹窗 |
| 拼团管理 | 活动新建/编辑/停用、拼团单列表与成员抽屉 |
| 轮播图 | 新增/编辑/删除，图片上传 |
| 系统配置 | 支付（易支付+测试连通+支付记录）、邮件（SMTP+测试邮件+发送日志）、短信（AK/SK+测试短信+发送日志）、应用（LOGO/客服/自动化/推荐奖励） |
| 销量统计 | 商品排行、销量占比进度条、CSV 导出 |
| 个人中心 | 修改个人信息、修改密码 |

## 目录结构

```
admin/
├── index.html
├── package.json
├── vite.config.js          # 端口 5173，代理 /admin、/uploads
└── src/
    ├── main.js
    ├── App.vue
    ├── api/                # request.js 封装 + 按模块拆分的 API
    ├── router/index.js     # 路由与登录守卫
    ├── store/admin.js      # Pinia：token / 管理员信息
    ├── styles/index.css    # 党建红主题全局样式
    ├── utils/format.js     # 金额/时间戳/状态映射
    ├── layout/AdminLayout.vue
    └── views/              # 登录、仪表盘、用户、分类、商品、订单、退款、配送、拼团、轮播图、配置、统计、个人中心
```

## 生产构建

```bash
npm run build
```

构建产物在 `dist/`，需将 `/admin`、`/uploads` 反向代理到后端服务。
